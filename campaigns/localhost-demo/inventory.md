# Localhost demo

A zero-setup campaign against the offline mock scenario. It needs no network and
no server, so it is the fastest way to watch the full loop run: enumerate, decide,
authorize, act, normalize, and grow the surface when reading the index leaks a
credential that unlocks the admin entrypoint.
