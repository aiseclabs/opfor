# Vue

A front-end framework. Its single-file components render elements carrying a scoped
`data-v-<hash>` attribute, and a server-rendered page marks its mount root with
`data-server-rendered`. This is a context tag on the host, what the site is built on, not a finding
and not a CVE lookup key, so the judge reads the role rather than treating the framework as a
vulnerability. Vue publishes no version plainly in a production build, so none is claimed, and a
pure client-side app that ships an empty mount point may not identify at all.
