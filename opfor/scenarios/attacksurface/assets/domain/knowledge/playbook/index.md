# Playbook

The cross-cutting judgment method every finding class shares, factored out so it is written
once and applied the same way to all of them rather than restated per class. Triage reads these
into the judge and the challenger at run time, so calibration is data a run can revise, not a
constant in code, invariant 1.

- `severity-rubric.md` One scale from INFO to CRITICAL, and what moves a grade.
- `false-positive-traps.md` The recurring look-alikes and the controlling fact that settles
  each, checked by the challenger and weighed by the finder.
- `methodology.md` How a run reaches a verdict and how the judge reads this knowledge.

A finding file adds only the grading nuance its own surface needs, it never restates this
layer.
