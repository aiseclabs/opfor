# Contract Signals

Mechanical detection data the enrichment capabilities apply. It is not judgment. A capability
matches these patterns and reports what hit, triage decides what a hit is worth.

- `interfaces.yaml` The fund-path function vocabulary and the access-guard keywords the
  `enum_interfaces` capability applies. A function whose name is a fund path is tagged, one the
  source gates behind a guard keyword is marked guarded.
- `risk-signals.yaml` The external-attacker source signatures the `scan_signals` capability
  matches, such as share accounting, oracle dependency, and delegatecall.
- `centralization-signals.yaml` The owner-power signatures, kept in their own category so they
  never raise the audit priority.

Adding a technique is an entry here, a data change, not a capability change, invariant 1.
